# Data Sources

원칙: 허가·라이선스가 확인되지 않은 외부 데이터는 다운로드·학습하지 않는다. 이 검토가 모든 법적 위험을 해소하지는 않는다.

## 현재 사용 중
| 데이터 | 출처 | 라이선스 | 상업 이용 | 검증 상태 |
|---|---|---|---|---|
| Discovery 상황/선택지, Coach 시나리오·개선 답변, Joke Library | 직접 작성한 Synthetic Demo Data (`backend/app/content.py`) | 프로젝트 소유 | 가능 | 완료 |

## 후보 (미다운로드, 미사용)
| 후보 | 출처 | 라이선스/약관 | 상업·AI 학습 | 상태 |
|---|---|---|---|---|
| YouTube/TikTok/Instagram 영상·자막·댓글 | 각 플랫폼 | 플랫폼 약관 + 저작권자 | 불가/미확인 | **사용 금지** |
| 방송·코미디 영상/대본 | 방송사/제작사 | 저작권 보호 | 별도 계약 필요 | **사용 금지** |
| 온라인 커뮤니티 대화 | 각 커뮤니티 | 약관·개인정보 이슈 | 미확인 | **사용 금지** |
| 공개 라이선스 한국어 대화 코퍼스 (예: CC 계열) | 미선정 | 조항별 확인 필요 | 미확인 | 검토 필요 |
| 동의 기반 Creator 제출 데이터 | 향후 프로그램 | 계약 | 계약 범위 내 | 미구축 |
| 사용자 대화/이미지 | 서비스 사용자 | 별도 명시 동의 필요 | 동의 전 불가 | 학습 미사용 |
