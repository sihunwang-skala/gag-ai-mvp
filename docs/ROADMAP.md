# Roadmap (MVP 이후)
1. **실제 LLM 품질 검증**: 평가 루브릭 골든셋(직접 작성) 구축, Mock vs LLM 비교, 프롬프트 개선.
2. **인증 + 동의 관리**: 계정, 학습 사용 opt-in/철회, 데이터 내보내기.
3. **Humor Profile 고도화**: 문항 확대, 시간에 따른 갱신, 코치/대화 신호 반영.
4. **Safety 강화**: 분류 모델 기반 가드레일, 신고 흐름, 연령/민감 주제 정책.
5. **Multimodal**: 비전 모델 실검증, 밈 템플릿 이해. 이후 음성/영상.
6. **Human Matching 파일럿**: 명시 동의 사용자 한정, 프라이버시 설계 선행.
7. **Creator 프로그램**: 동의·계약·수익배분 → Creator AI. 유명인은 공식 라이선스만.
8. **B2B API**: 평가/프로필 API, 인증·과금·감사 로그.
